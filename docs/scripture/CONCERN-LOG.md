## What remains unresolved

The first review deliberately prioritizes public quotations, readiness applications, and common context-sensitive corpus texts. It does **not** complete the hundreds of remaining per-passage reviews. `pending-contextual-review` means there is no approved speaker/audience analysis, literary boundary, historical framing, or application assessment for that record. A cached full chapter must not be treated as filling those fields.

Source scanning produces both quotation records and broader claim candidates. Comments, example references, and dynamic templates need classification. Manually paired JSX quotations are retained in `manual-quotation-pairs.json` with baseline locations; line numbers can move during UI work. Third-party resources linked by the site are not endorsed by this scan, and no external resource library was represented as fully reviewed.

NIV/ESV-like wording remains unverified unless its precise source is established. The quotation table supplies the pinned WEB comparison text in the JSON inventory; it does not silently substitute that text. Permission requirements should be assessed against the actual publication use and the owners' current terms, not by deleting citations.
